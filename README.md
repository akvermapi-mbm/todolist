# 📝 To-Do List App

A simple, beautiful to-do list application that saves your tasks in your browser's localStorage.

![App Screenshot](screenshot.png)  <!-- Add a screenshot later -->

## ✨ Features

- ✅ Add, delete, and complete tasks
- ✏️ Double-click to edit tasks
- 🔍 Filter tasks (All / Active / Completed)
- 💾 Tasks persist after page refresh (localStorage)
- 📱 Responsive design (works on mobile)
